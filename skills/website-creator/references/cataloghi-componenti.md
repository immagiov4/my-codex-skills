## Spline: cloud authoring and delivery boundaries

Spline's [21 October 2026 announcement](https://www.youtube.com/watch?v=tWNgzLG9-2c) points to its [plugin documentation](https://docs.spline.design/generate/plugins/chatgpt) and [MCP reference](https://docs.spline.design/generate/spline-mcp-server), checked 2026-10-26. The hosted route authors editable Spline 3D or Hana files in the account's cloud editor; it differs from the desktop server that operates on open local editor tabs. OAuth access and plan-based daily/per-minute call limits apply. Documentation was inspected; connection, generation and export remain pending in this collection.

For an interactive 3D product scene, establish the object's geometry, camera, material and required interaction first. Select the cloud or desktop route appropriate to authorized inputs, inspect a screenshot of the resulting file, then check the selected publish/export operation against the plan. Hana's documented HTML/CSS export and Spline 3D code/self-hosted export are different paths: [pricing](https://spline.design/pricing) places 3D code/self-hosted export in Enterprise, watermark-free 3D web export in Hobby and video export in Pro. An authoring connection alone does not establish a permitted deliverable. Apply the existing 3D recipe's mobile, loading and reduced-motion checks to the embedded result.
