## React Bits: evidence for the free tools

The [official Tools page source](https://github.com/DavidHDev/react-bits/blob/main/src/pages/ToolsPage.jsx) describes them as free utilities. Targeted source inspection confirms browser export implementations. This establishes public-code behavior; a downloaded result in the deployed interface requires a separate test.

| Tool | Export confirmed in official code | Use in a recipe |
|---|---|---|
| [Background Studio](https://www.reactbits.dev/tools/background-studio) | [PNG and WebM recording](https://github.com/DavidHDev/react-bits/blob/main/src/tools/background-studio/BackgroundStudio.jsx) from canvas through `toDataURL`, `captureStream`, `MediaRecorder`, and a download link; the inspected source records 10 seconds. Its [Controls panel](https://github.com/DavidHDev/react-bits/blob/main/src/tools/background-studio/Controls.jsx) generates an install command and configured JSX. | Prefer the configured component for a webpage; use PNG/WebM for previews or appropriate assets. Browser recording depends on supported codecs: inspect the generated file in Chrome. This procedural animation requires no paid video-generation service. |
| [Shape Magic](https://www.reactbits.dev/tools/shape-magic) | [Official Controls](https://github.com/DavidHDev/react-bits/blob/main/src/tools/shape-magic/Controls.jsx) copies SVG/React/CSS clip-path and downloads SVG, using locally imported generators. | Use SVG/CSS for merged shapes, frames, and masks. Check the desired format in the interface before promising a particular export variant. |
| [Texture Lab](https://www.reactbits.dev/tools/texture-lab) | [Official TextureLab](https://github.com/DavidHDev/react-bits/blob/main/src/tools/texture-lab/TextureLab.jsx) calls `exportCanvas` for images and records video with `MediaRecorder`; see [utilities](https://github.com/DavidHDev/react-bits/blob/main/src/tools/texture-lab/utils.js). The code identifies remote-media CORS restrictions that can prevent export/copy. | Apply texture to your own locally loaded media or a procedural texture. Export a light image before considering video. |

These findings support “free tools with export implemented in public code.” A file exported and inspected in Chrome supports the subsequent claim “export verified.” Respect the code's [MIT + Commons Clause conditions](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md): retain notices and license when using components in a website. A distributed skill stores recipes and references rather than repackaging their source.
