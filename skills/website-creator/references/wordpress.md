## W01

### From a composition to an editable Elementor page

A page preserves the reference while allowing content edits in the builder.

Procedure:

1. Use an authorized composition and your own product image; first build the HTML section for comparison.

2. Generate Elementor JSON and complementary CSS for the installed version. Import into a Canvas page in the local copy and apply the CSS; the video shows this at 7:44.

3. Correct containers, images, and footer in the editor, then check that the parts are actual Elementor controls.

4. Verify heading, image, and action edits in the editor and confirm that the published page retains the layout.

The tutorial uses external products and links: choose components already available to the website and verify their plans.

Source steps: [Rbbus1K8R8g · 0:00](https://www.youtube.com/watch?v=Rbbus1K8R8g&t=0s), [iithedEMvew · 0:00](https://www.youtube.com/watch?v=iithedEMvew&t=0s).

Result check: Editing text in the builder updates the page while retaining its mobile layout.

2. The tutorial uses NovaMira through MCP; at 8:07 it shows HTML inside a Gutenberg block. When that structure meets the project's needs, prepare HTML in the website's existing system.
