# Website Creator

Create a visual identity grounded in the subject, then choose recipes to implement it. This collection contains procedures synthesized from 2026 videos, links to the original steps, official resources, and captured examples. Codex adaptations and combinations are labeled explicitly.

For a selected mockup or Image Gen refinement, first read [Implement a visual reference faithfully](references/reference-fidelity.md). ## Apply a workflow

1. Establish the content, visitor task, and visual target. Follow the reference-fidelity workflow for a selected image, or complete the direction check for a new identity; then choose the recipe. Website combinations suggest content and interactions; the visual target determines their composition.
2. Read the recipe and video entry. When motion determines the result, open the linked step in Chrome or the available browser, mute playback, and observe the initial, middle, and final states. For a static reference, compare proportions, crop, text, and control placement.
3. Reuse the project's structure and dependencies. For a new static website, start with HTML/CSS and the necessary JavaScript; in an application, adapt the recipe to existing components. Read the component code and license before integration.
4. Translate tutorial operations into local files and tools available to Codex. Installation, access, and publication follow the current request. Prepare metered external steps with a model, parameters, and cost estimate before obtaining spending authorization.
5. Build a static section with real content first, then its defining motion. Compare the page with the reference in the browser. Correct a concrete difference at a time, such as object crop, heading size, or scroll interval.
6. Test the complete section on desktop and mobile, including reduced motion. For sequences and 3D, test scrolling both ways, resizing, and entry into the next section; for controls, test keyboard use and relevant loading, empty, and error states. For a new or replacement identity, complete the visual review and Impeccable scan in [Choose a visual direction](references/design-direction.md#review-the-built-page). Completion requires an observed result and usable content.

## Choose the free route

Free access belongs to the individual component and its license. Temporary trials and introductory credits are labeled accordingly. Use native Codex image generation when available, within the account's limits. For abstract motion, try CSS, SVG, or programmed animation. For a moving photographic scene, follow the [video workflow](references/immagini-video.md).

Recipe prompts are original formulations for Codex. Preserve author attribution when explaining a workflow's origin. Captured frames document examples to study; use authorized images and content in the resulting website.

## Read the evidence

The catalog distinguishes YouTube metadata, transcripts, observed frames, author workflows, and collection adaptations. A frame establishes composition; behavior in the implemented website requires the recipe's test. Prices, licenses, and interfaces carry a verification date: refresh the fact that determines a choice before a new installation or purchase.
