# Website tools in Geppetto

The collection lives in the `website-tools` bucket of the configured Geppetto memory repository. Use `$geppetto-memory` to resolve the checkout and read `buckets/website-tools/index.md`, then follow its guide or maintenance page for the requested task.

[Canonical bucket](https://github.com/immagiov4/llm-memories/tree/main/buckets/website-tools). Maintain the collection at that owner; this skill is a compatibility pointer.
